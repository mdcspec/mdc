# Markdown Checklists

> **Superseded.** This note is kept as historical provenance. The research in [docs/](docs/README.md) scrapped the bare `.mdc` extension (ceded to Cursor; GitHub won't render it), `.mdb` (Microsoft Access), and the spreadsheet-format ideas. The living project is **MDC — Markdown Checklists**: canonical filename `*.mdc.md`, in-band `mdc:` frontmatter detection, built around the gap the research surfaced — durable, diffable task state shared by humans and AI agents. Start at [docs/README.md](docs/README.md).

.mdc - markdown checklists

The idea for this research endeavor and potential R&D effort is to create a new standard called markdown checklist (Markdown Checklists); using the .mdc extension.

This would build on the Markdown file extension/file type - but carve out a specific niche for more interactivity, optimization, and use cases - drive by checklists within markdown.

We should likely also carve out an idea/product space around .mddb (or .mdb) which would be markdown database; essentially if we have checklists go into a much more complex direction, how do we support with a specific more database-like standard. Note: I considered introducing a .mdxl / .mdcv for some type of spreadsheet/comma-delimited file formated; but just jumping right to DB and allowing someone to build a spreadsheet on top of that if needed at some point seemed more appropriate.
