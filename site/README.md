# mdcspec.dev

The public website for the **MDC (Markdown Checklists)** project, built with
[Astro](https://astro.build) + [Starlight](https://starlight.astro.build) and
deployed to GitHub Pages at [mdcspec.dev](https://mdcspec.dev).

## Run locally

```sh
npm install
npm run dev
```

`npm run dev` (and `npm run build`) first run `scripts/sync-content.mjs`, then
start Astro. Open http://localhost:4321.

## Build

```sh
npm run build     # → dist/
npm run preview   # serve the built site locally
```

## Content is single-sourced from the repo

The specification pages are **not** hand-maintained here. On every build,
`scripts/sync-content.mjs` copies the canonical documents out of the repo into
`src/content/docs/`, prepends Starlight frontmatter, and rewrites repo-relative
markdown links (to site routes for the three synced pages, to GitHub blob URLs
for everything else):

| Repo source | Site route |
| --- | --- |
| `spec/mdc-spec-v0.1.md` | `/spec/v0.1` |
| `spec/conformance.md` | `/conformance` |
| `docs/spec/implementations.md` | `/implementations` |

The synced files are git-ignored and regenerated by the build, so edit the
sources in the repo — never the copies under `src/content/docs/`.

## Deploy

Pushing to `main` with changes under `site/**`, `spec/**`, `docs/spec/**`, or
the workflow file triggers `.github/workflows/site.yml`, which builds the site
and publishes `dist/` to GitHub Pages.
